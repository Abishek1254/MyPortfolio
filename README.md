# 💼 Personal Portfolio Website

Welcome to my personal portfolio website — a sleek, responsive web app built using **Next.js**, **TypeScript**, and **Tailwind CSS**. This site showcases my journey, skills, projects, and achievements in a well-structured and engaging format.

## 🌐 Live Site

Check out the live version here: https://my-portfolio-rho-two-87.vercel.app/

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 📂 Features

- ⚡ Fast and fully responsive design for desktop and mobile
- 🎨 Clean, modern UI with smooth transitions
- 🧠 Sections include:
  - **Home** – Greeting with animated header
  - **About Me** – Background, education & interests
  - **Projects** – Selected works with live links & code
  - **Contact Me** – Socials and ways to connect
